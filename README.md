# Self-financing Post-secondary Scholarship Scheme — Excel VBA Tools

This repository contains Excel VBA macros and the macro-enabled dataset used for managing and processing scholarship award records.

## Repository Contents

* **`scholarshipAwarded.xlsm`**: The main Excel Macro-Enabled Workbook containing the dataset and embedded VBA macros.
* **`*.bas` / VBA Scripts** *(if stored separately)*: Standalone VBA module files for sheet management and data processing (e.g., deleting worksheets).

## Data Source

The dataset in `scholarshipAwarded.xlsm` is sourced from the Hong Kong Government Open Data Portal (**DATA.GOV.HK**):

* **Dataset Title:** Scholarships/ Awards Information
* **Original Resource Name:** *Scholarships/ Awards Granted under Self-financing Post-secondary Scholarship Scheme (English)*
* **Source URL:** [https://data.gov.hk/en-data/dataset/hk-edb-cspe-awards](https://data.gov.hk/en-data/dataset/hk-edb-cspe-awards)
* **Data Provider:** Education Bureau (EDB)
* **Maintainer:** Secretariat, Committee on Self-financing Post-secondary Education
* **Update Frequency:** Annually
* **Data Dictionary:** [Data Specification PDF](https://cspe.edu.hk)
